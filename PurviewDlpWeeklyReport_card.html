Purview DLP Weekly Report

PurviewDlpWeeklyReport
Microsoft Purview の DLP アクティビティを Defender の CloudAppEvents から週次集計し、 適用された秘密度ラベルと利用クラウドサービスを判別。視認性の高い HTML/CSS レポートを Azure Logic App 経由でメール配信します。
🔧Skills: 5
📦Skill Groups: 3
📐Formats: Agent, KQL, LogicApp
🗄️Data Source: Defender CloudAppEvents
⏰Trigger: Weekly (604800s)
🔒Auth: None
⚠️ 前提条件: CloudAppEvents に Purview DLP 監査レコード （RawEventData.Operation = DLPRuleMatch / DLPRuleUndo）が投入されるには、 Microsoft 365 と Defender for Cloud Apps の接続と DLP ポリシーの稼働が必要です。 DLP レコードが無い場合、レポートに注意バナーと「データなし」を明記します（架空データは生成しません）。
